# Frontend

Vue 3 + TypeScript + Vite 前端。

完整的项目介绍、环境变量、Windows 启动步骤与功能说明见仓库根目录 **[README.md](../README.md)**。

## 本地开发（摘要）

```bat
cd /d D:\project\ai-assistant\frontend
npm install
npm run dev
```

默认开发地址：`http://127.0.0.1:5173`（以终端输出为准）。
API 基址在 `src/utils/request.ts` 中配置为 `http://127.0.0.1:8000`，请先启动后端。
